# help-desk-ticketing-system-demo

Web application demo for managing support requests.

## Overview

Realizza un'applicazione web demo per la gestione delle richieste di assistenza (Help Desk / Ticketing System).

L'applicazione deve consentire di simulare l'intero ciclo di vita di un ticket di supporto.

Funzionalità principali:

Dashboard con KPI (ticket aperti, chiusi, in lavorazione, tempo medio di risposta).
Creazione di nuovi ticket tramite form.
Elenco ticket con filtri per stato, priorità e categoria.
Visualizzazione dettagliata del ticket con cronologia attività.
Assegnazione ticket agli operatori.
Cambio stato (Nuovo, Preso in carico, In lavorazione, Risolto, Chiuso).
Sistema di commenti interni e note operative.
Ricerca avanzata e ordinamento.
Gestione utenti con ruoli (Amministratore, Operatore, Cliente).

Requisiti UI/UX:

Design moderno e professionale.
Sidebar di navigazione.
Dashboard con grafici interattivi.
Tabelle responsive con paginazione.
Tema chiaro e scuro.
Layout completamente responsive.

Dati demo:

Almeno 50 ticket di esempio.
10 utenti demo con ruoli differenti.
Statistiche generate automaticamente.

Aspetti tecnici:

Nessuna integrazione esterna necessaria.
Backend simulato con dati mock.
Validazione dei form.
Gestione degli errori e notifiche utente.

Obiettivo:
Creare una demo realistica per presentazioni, test funzionali, formazione utenti e valutazione dell'esperienza d'uso.
